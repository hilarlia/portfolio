BBPSSW entanglement purification in Lean

Lean code and verification of the BBPSSW protocol

← Back to My Project

BBPSSW in plain terms

BBPSSW stands for Bennett–Brassard–Popescu–Schumacher–Smolin–Wootters, a quantum-information protocol designed to improve the quality of entanglement shared between two remote parties. In practice, two noisy entangled pairs (qubits connected across space) are processed with local operations and simple classical communication to produce fewer pairs with higher fidelity to a perfect entangled state. The BBPSSW protocol is a concrete recipe for such purification, using measurements and local gates to distill better entanglement. In this Lean project, we model a single round of that protocol on two Werner states and verify (auditable, machine-checked) properties about the fidelity improvement. The narrative here is aimed at a non-specialist audience (AeroAstro), so we emphasize intuition and practical meaning rather than the algebraic details.

Scope

The project encodes a complete, verified Lean formalization of a single round of the BBPSSW entanglement purification protocol for two Werner pairs. The formalization includes local operations, Bell projectors, a finite twirl, and a proof that the fidelity improves within the trusted range (1/2 < F < 1).

The Lean code lives in the bbpssw-lean directory. The repository ships with a ready-to-run verification workflow and a published audit routine to ensure there are no hidden axioms beyond the usual propositional logic foundations.

Paper and precise scope

The BBPSSW Lean project follows the same target as the Physical Review Letters BBPSSW paper but remains focused on a single round and a finite twirl. The main theorems track fidelity improvement and the positive probability of successful purification within the given fidelity window.

Mathematical definitions (Lean perspective)

The formalization uses a small collection of primitives: Bell projectors, Werner states, twirl operators, and the BBPSSW recurrence rules. See the bbpssw-lean directory for the exact Lean modules (BBPSSW, Recurrence, Protocol, Twirl, Main, and Audit).

A typical development note is that a state is encoded as a density-like object, and the theorems are proved using Lean’s typeclass and algebraic infrastructure. The code mirrors the paper’s structure while staying explicit about assumptions and verifications.

File guide

  • BBPSSW/Basic.lean — Exact complex matrices, Bell projectors, positivity, trace, fidelity
  • BBPSSW/Recurrence.lean — Rational recurrence, denominator positivity, success bound, strict gain
  • BBPSSW/Protocol.lean — Local CNOT, measurement branches, accepted state, normalization
  • BBPSSW/Twirl.lean — Local Clifford averaging and complete state-level recurrence
  • BBPSSW/Main.lean — Main physical correctness theorem
  • Audit.lean — Transitive axiom whitelist audit and printed main theorem

The exact example F = 3/4 is included as example_three_quarters in the verification suite, confirming the computed probabilities and fidelity updates.
