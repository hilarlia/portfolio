# Research writing guidance

Write precise, original scholarly prose. Define technical terms before use; keep abstracts and introductions accessible; distinguish statements, assumptions, evidence, and limitations. Preserve existing notation and proofs unless an approved change requires otherwise. Verify every citation against the source.

Use `\writerrevision{...}` for the latest completed Writer generation (magenta) and `\writerpreviousrevision{...}` for earlier changes (blue). Each run rotates incoming current markers in its disposable copy before adding new current markers. Preserve macro declarations and case-safe color aliases.
